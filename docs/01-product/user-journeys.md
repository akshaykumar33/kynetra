# Core User Journeys

### Journey 1: New Developer Onboarding
1. User logs into Kynetra via 2D web shell.
2. User customizes profile, selects engineering discipline (e.g. Backend, Frontend, Cloud, AI).
3. User spawns at Kynetra Central Plaza.
4. AI Receptionist welcomes developer and directs them to Innovation Tower Floor 1.
5. Developer completes initial environment test in the Coding Arena and earns their first verified badge.

### Journey 2: Incident Response Simulation
1. An alert triggers in the NOC/Operations District.
2. Developer receives a notification and transitions to the Incident Lab.
3. Developer inspects live telemetry, isolates the regression, submits a hotfix patch, runs integration tests, and resolves the simulated outage.
