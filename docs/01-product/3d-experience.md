# 3D Experience Specification

The 3D world is delivered entirely in the browser via Three.js and React Three Fiber.

## Visual Direction
- Modern architectural aesthetic inspired by modern technology campuses.
- Dynamic day/night cycle and ambient lighting.
- Smooth camera interpolation during interactions (e.g. approaching a workstation smoothly zooms into the screen).
- Strict performance budget: 60 FPS on mid-range hardware, <50 draw calls per scene zone.
