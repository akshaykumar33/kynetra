# Design System & Tokens

Tokens for color palettes, spacing, border radii, elevation, and motion curves.
- Backgrounds: Dark slate (`#0B0F17`, `#111827`).
- Accents: Electric cyan (`#06B6D4`), Emerald (`#10B981`), Amber (`#F59E0B`).
- Typography: Inter for UI, JetBrains Mono / Fira Code for technical telemetry.
