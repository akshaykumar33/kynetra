# Product Vision: Kynetra

Kynetra is an **Open Digital IT World**: a persistent virtual technology city that mirrors meaningful procedures and workflows of the real technology industry.

## The Core Concept

Humans and AI agents collaborate, learn, build software, operate infrastructure, resolve incidents, attend conferences, and participate in a persistent economy.

### Key Tenets
1. **Unified World State**: The platform is not divided into separate "games" or "websites". 2D Web, 3D Web, Mobile, and XR clients are different projection lenses over a single authoritative world state.
2. **Procedural Realism Over Photorealism**: High procedural fidelity (code compiles, servers crash, metrics spike, PR reviews gate deployments) matters infinitely more than high-poly graphics without functional depth.
3. **The Metaverse as an Interface**: The 3D world is an immersive interface to an underlying cloud and simulation platform — not an empty virtual chat room.
