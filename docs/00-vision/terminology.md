# Terminology & Ubiquitous Language

- **Kynetra Central**: The founding district of the digital city housing central plaza and headquarters.
- **Innovation Tower**: The flagship high-rise containing workspaces, meeting rooms, coding arenas, and labs.
- **World Platform**: The central domain and simulation backend maintaining the authoritative state of all entities, spaces, and objects.
- **Projection**: A specific client interface (2D web, 3D WebGL/WebGPU, mobile, XR) rendering world state.
- **Workstation**: An in-world terminal station connecting the user to cloud development environments.
- **Incident Range**: An isolated sandbox where outages, security vulnerabilities, or infrastructure failures are simulated.
- **XP / Evidence**: Cryptographically verifiable proof of skill completion (e.g. passing test suites, remediating CVEs).
