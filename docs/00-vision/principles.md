# Core Product Principles

### 1. Procedural Realism First

Preserve meaningful real-world software engineering and IT procedures without reproducing tedious bureaucracy.

### 2. Efficiency Parity (2D ↔ 3D)

Never force a user to walk for five minutes through a 3D city to perform an action that takes one second in a 2D web console. 2D is the high-efficiency control surface; 3D is the spatial immersion and discovery layer.

### 3. Progressive Fidelity

System fidelity evolves in stages:

- **Visual Realism**: Believable architecture, clean typography, dynamic lighting, spatial audio.
- **Social Realism**: Proximity audio, team dynamics, organic encounters.
- **Procedural Realism**: Interviews, meetings, employment, pull requests, deployments.
- **System Realism**: Code executes, databases persist, AI agents execute bounded tools, infrastructure responds.

### 4. Zero Résumé-Driven Engineering

No technology (Kafka, Kubernetes, Rust, Go, Neo4j, ClickHouse) is introduced without a concrete problem statement, cost-benefit analysis, migration strategy, and documented ADR.
