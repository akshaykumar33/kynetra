# User Personas

### 1. Software Engineer / Developer (Dev)
- **Goal**: Build software, solve coding quests, collaborate on open-source projects, prove engineering competency with verifiable evidence.
- **Workflows**: Terminal/workstation access, coding arenas, code reviews, debugging simulations.

### 2. Engineering Leader / Tech Lead
- **Goal**: Form teams, architect systems, mentor developers, review pull requests, orchestrate incident triage.
- **Workflows**: Team dashboards, architecture boards, sprint rooms, code governance.

### 3. Student / Career Switcher
- **Goal**: Learn practical programming, complete interactive cloud/cyber labs, undergo AI-assisted technical interviews, get hired.
- **Workflows**: Academy district, mentor NPCs, interview simulators, interactive tutorials.

### 4. Recruiter / Hiring Manager
- **Goal**: Discover candidates based on verified in-world code execution and problem-solving evidence rather than self-reported resumes.
- **Workflows**: Talent search, coding challenge observation, interview rooms.

### 5. Autonomous AI Agent / NPC
- **Goal**: Act as mentors, receptionists, interviewers, mock customers, SRE incident responders, and synthetic teammates.
- **Workflows**: Tool calling via AI gateway, bounded environment execution, stateful memory.
