# Non-Goals

### Phase 00–01 Non-Goals

1. **No Proprietary MMO Game Engine**: We do not build an engine from C++ scratch; we leverage WebGL/WebGPU, Three.js, React Three Fiber, and standard web technologies.
2. **No Speculative Microservices**: We will not break services into dozens of microservices until load or organizational boundaries mandate it. A modular monolith is preferred.
3. **No Crypto / Blockchain Speculation**: Virtual economy points, skill badges, and achievements are managed through robust PostgreSQL transactional models, not volatile web3 tokens.
4. **No Photorealistic Unreal Client in Phase 0**: High-fidelity native clients are deferred to later phases once browser-based core loops are proven.
