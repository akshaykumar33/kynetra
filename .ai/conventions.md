# Engineering Conventions

- **Commits**: Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:`, `test:`, `refactor:`, `ci:`, `perf:`).
- **File Naming**: Kebab-case for files and directories (e.g. `district-service.ts`, `world-map.tsx`).
- **Imports**: Use workspace package specifiers (e.g. `import { WorldDistrict } from '@kynetra/contracts'`).
